# Just More Than Enough Guns

Just More Than Enough Guns (JMTEG) is a Forge 1.20.1 compatibility mod that lets Recruits use Just Enough Guns firearms more intelligently.

## Features

- Detects JEG guns in recruit inventories.
- Replaces incompatible recruit ranged goals with a JEG-aware gunner goal.
- Supports ammo-aware reloads from recruit inventories, player inventories, and offhand fallback.
- Adds role-based gun selection for Bowman and CrossBowman recruits.
- Provides configurable gun role pools in `config/jmteg/recruit_roles.json`.
- Adds role-aware movement, target selection, burst fire, reload handling, and arm pose support.

## Required Mods

- Minecraft Forge 1.20.1
- Just Enough Guns 0.13.2 or newer
- Recruits 1.15.0 or newer

JMTEG does not add new guns by itself. It is an integration layer between Just Enough Guns and Recruits.
